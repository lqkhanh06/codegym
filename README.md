# CodeGym - Thực Hành SQL

Kho lưu trữ bài tập và thực hành cơ sở dữ liệu MySQL tại CodeGym.

## Nội dung bài thực hành:
- **Tên bài:** [Thực hành] Thêm dữ liệu vào trong cơ sở dữ liệu quản lý sinh viên.
- **Mục tiêu:** Sử dụng thành thạo câu lệnh `INSERT INTO` để thêm dữ liệu vào các bảng `Class`, `Student`, `Subject`, và `Mark`.
- **File thực thi:** [`QuanLySinhVien_InsertInto.sql`](QuanLySinhVien_InsertInto.sql)
